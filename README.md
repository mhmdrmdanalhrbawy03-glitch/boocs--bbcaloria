# المكتبة التعليمية الشاملة - تانية بكالوريا والثانوية العامة

منصة تعليمية متطورة مبنية بـ React + Vite + TypeScript + Tailwind CSS ومربوطة بقاعدة بيانات سحابية (Firebase Firestore) ولوحة تحكم متكاملة للمعلمين.

## المميزات
- 📚 مكتبة كتب ومذكرات تفاعلية مع إمكانية القراءة المباشرة والتحميل.
- 👨‍🏫 لوحة تحكم كاملة للمعلم لإضافة وتعديل وحذف الكتب، التقييمات، والأسئلة، والإعلانات.
- 📝 بنك أسئلة واختبارات تفاعلية مع عداد زمني وتصحيح فوري وشرح المعلم.
- 📋 قسم التقييمات والواجبات الأسبوعية مع نماذج الإجابات الرسمية.
- 🕌 واحة القرآن الكريم وأدعية التفوق والاستذكار.
- ⚡ نشر تلقائي على Vercel و Firebase.
